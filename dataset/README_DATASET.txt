This directory stores the generated dataset files.

Generated by running:
    python src/01_dataset_generation.py

Contents after generation:
  - dataset.npz              — Main dataset archive (images, freq_resp, poles_vec, zeros_vec, labels)
  - metadata.csv             — Per-sample metadata (label, class_name, n_poles, n_zeros)
  - class_distribution.csv   — Count per class
  - history_cnn.json         — CNN training history
  - history_mlp.json         — MLP training history
  - history_fusion.json      — FusionNet training history
  - best_cnn.pt              — Best CNN checkpoint
  - best_mlp.pt              — Best MLP checkpoint
  - best_fusion.pt           — Best FusionNet checkpoint
  - training_summary.json    — Summary of all training runs

Note: .npz and .pt files are excluded from git via .gitignore (too large).
      Regenerate them locally by running the pipeline.
